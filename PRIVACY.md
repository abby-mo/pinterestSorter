# Privacy Policy: Pin Sorter

_Last updated: November 27, 2026_

Pin Sorter is a personal, non-commercial tool that helps its developer sort their own Pinterest pins into boards. It runs only on the developer's own computer. It is not offered to the public and has no other users.

## What the app accesses

Once the account owner signs in with Pinterest and grants permission, the app uses the official Pinterest API to:

- read the signed-in user's own profile name, boards, and pins
- create a board, when the user asks for one
- save copies of pins the user chooses onto a board the user chooses

The app only accesses the signed-in user's own account. It does not access other Pinterest users' data.

## What the app never does

- It never deletes, moves, or edits pins or boards.
- It never sells, shares, rents, or transfers any data to anyone.
- It never sends data to any server other than Pinterest's own API.
- It does not use analytics, tracking, advertising, or cookies for tracking.

## What is stored, and where

All data stays on the user's own computer, in a local folder:

- **Pinterest access tokens:** used to stay signed in. They are never sent to the web browser or to any third party.
- **Sorting progress:** which pins have been saved or skipped, so a session can be resumed.
- **A queue of pending saves:** so a failed save can be retried later.

Pin images and details are loaded from Pinterest when displayed, and are only cached on the local computer as needed to show the sorting progress and a summary of saved pins.

## Keeping or deleting data

The user can disconnect at any time. To do this, either:

- delete the app's local data folder, which erases all stored tokens and progress, or
- revoke the app's access in Pinterest's settings (Settings → Security and logins → Apps).

Deleting the local data does not affect anything on Pinterest.

## Children

The app is a personal tool and is not directed at children.
